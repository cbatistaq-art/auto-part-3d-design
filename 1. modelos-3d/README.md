# 🧩 Modelos 3D

Esta carpeta contiene los archivos originales y editables de los
diseños tridimensionales de las piezas plásticas automotrices.

## Objetivo

Almacenar los modelos 3D para facilitar su modificación,
optimización y reutilización.

## Formatos admitidos

- `.f3d` - Autodesk Fusion 360.
- `.FCStd` - FreeCAD.
- `.blend` - Blender.
- `.step` - Formato CAD de intercambio.
- `.obj` - Modelo tridimensional.

## Requisitos

- Utilizar milímetros como unidad de medida.
- Identificar la marca, modelo y año del vehículo.
- Documentar las dimensiones de la pieza.
- Identificar la versión del diseño.
- Mantener los archivos originales editables.

## Nomenclatura

`marca-modelo-pieza-v1.0.extension`
