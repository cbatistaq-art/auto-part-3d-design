# 🖨️ Archivos STL

Esta carpeta almacena los modelos exportados en formato STL
para su fabricación mediante impresión 3D.

## Objetivo

Facilitar la fabricación y reproducción de las piezas
plásticas automotrices desarrolladas en el proyecto.

## Materiales sugeridos

| Material | Características |
|---|---|
| PLA | Prototipos iniciales |
| PETG | Resistencia mecánica y moderada al calor |
| ABS | Resistencia térmica y mecánica |
| ASA | Resistencia a la radiación UV y al exterior |
| Nylon | Resistencia al desgaste |

## Parámetros iniciales de impresión

- Altura de capa: 0.2 mm.
- Relleno: 40 % - 60 %.
- Paredes: 4.
- Temperatura: según el material.
- Soportes: según la geometría.
- Orientación: según las cargas previstas.

Estos parámetros son orientativos y deberán validarse
según las características de cada pieza.

## Nomenclatura

`marca-modelo-pieza-v1.0.stl`

## Lista de verificación

- [ ] Modelo sin errores geométricos.
- [ ] Dimensiones verificadas.
- [ ] Orientación de impresión definida.
- [ ] Material seleccionado.
- [ ] Prototipo fabricado.
- [ ] Pruebas realizadas.
