## 🚀 Pasos para contribuir

### 1. Realizar un Fork

Crea una copia del repositorio en tu cuenta de GitHub utilizando
el botón **Fork**.

Esto permitirá realizar modificaciones sin afectar directamente
el repositorio principal.

### 2. Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/TU-USUARIO/auto-part-3d-design.git
```

Reemplaza `TU-USUARIO` por tu nombre de usuario de GitHub.

### 3. Acceder al proyecto

```bash
cd auto-part-3d-design
```

### 4. Crear una nueva rama

Crea una rama independiente para realizar tus modificaciones.

```bash
git checkout -b mejora-diseno-3d
```

Ejemplos de nombres de ramas:

- `feature/nueva-pieza`
- `fix/error-dimensiones`
- `docs/actualizar-documentacion`
- `design/mejorar-prototipo`
- `test/prueba-resistencia`

### 5. Realizar los cambios

Desarrolla tus mejoras y coloca los archivos en las carpetas
correspondientes.

Procura mantener una estructura organizada y documentar todas
las modificaciones importantes.

### 6. Verificar los cambios

Antes de guardar las modificaciones, verifica los archivos.

```bash
git status
```

### 7. Guardar los cambios

```bash
git add .
git commit -m "Mejora del diseño de la pieza automotriz"
```

Los mensajes de los commits deben ser claros y descriptivos.

### 8. Subir los cambios

```bash
git push origin mejora-diseno-3d
```

### 9. Crear un Pull Request

Desde GitHub, crea una solicitud de incorporación de cambios
(Pull Request) hacia la rama principal del repositorio original.

Incluye una descripción clara de las modificaciones realizadas.

### 10. Participar en la revisión

El administrador o los revisores podrán solicitar cambios,
realizar observaciones o recomendar mejoras.

Participa activamente en este proceso y realiza las correcciones
necesarias.

### 11. Integración de la contribución

Una vez aprobada, la contribución podrá incorporarse al
repositorio principal y estará disponible para la comunidad.

## 📐 Requisitos para los diseños 3D

Todos los diseños deberán cumplir las siguientes recomendaciones:

- Utilizar milímetros como unidad de medida.
- Incluir dimensiones y tolerancias.
- Identificar la marca, modelo y año del vehículo.
- Identificar el número de pieza original, si está disponible.
- Incluir archivos STL y, preferiblemente, STEP.
- Conservar los archivos originales editables.
- Documentar el material recomendado.
- Incluir fotografías o capturas del diseño.
- Evitar errores geométricos.
- Verificar las superficies y geometrías del modelo.
- Identificar la versión del diseño.
- Documentar las pruebas de ajuste y funcionamiento.
- Especificar las limitaciones conocidas de la pieza.
- Identificar si el diseño es experimental o ha sido validado.

### Formatos de archivos admitidos

| Formato | Descripción |
|---|---|
| STL | Modelo para impresión 3D. |
| STEP | Formato CAD de intercambio. |
| OBJ | Modelo tridimensional. |
| 3MF | Formato para fabricación aditiva. |
| F3D | Archivo de Autodesk Fusion 360. |
| FCStd | Archivo de FreeCAD. |
| BLEND | Archivo de Blender. |
| PDF | Planos y documentación técnica. |
| PNG | Capturas y evidencias gráficas. |
| JPG | Fotografías del proyecto. |
| MD | Documentación Markdown. |

### Materiales de fabricación

| Material | Aplicación orientativa |
|---|---|
| PLA | Prototipos y pruebas iniciales. |
| PETG | Piezas con requerimientos mecánicos moderados. |
| ABS | Aplicaciones que requieren mayor resistencia térmica. |
| ASA | Piezas expuestas a condiciones exteriores. |
| Nylon | Aplicaciones con requerimientos de resistencia al desgaste. |
| TPU | Componentes flexibles. |
| PC | Aplicaciones con mayores requerimientos térmicos y mecánicos. |

La selección del material dependerá de las condiciones de uso,
temperatura, exposición ambiental y cargas de cada pieza.

## 📂 Organización de archivos

El repositorio deberá mantener una estructura organizada que
facilite la búsqueda y reutilización de la información.

| Carpeta | Contenido |
|---|---|
| `modelos-3d/` | Diseños originales y editables. |
| `archivos-stl/` | Archivos para impresión 3D. |
| `archivos-step/` | Archivos CAD de intercambio. |
| `imagenes/` | Fotografías, renderizados y capturas. |
| `documentacion/` | Especificaciones técnicas y manuales. |
| `pruebas/` | Resultados y evidencias de las evaluaciones. |

### Estructura del repositorio

```text
auto-part-3d-design/
│
├── modelos-3d/
├── archivos-stl/
├── archivos-step/
├── imagenes/
├── documentacion/
├── pruebas/
│
├── README.md
├── CONTRIBUTING.md
├── CODE_OF_CONDUCT.md
├── CHANGELOG.md
└── LICENSE
```

### Nomenclatura de archivos

Se recomienda utilizar la siguiente estructura:

```text
marca-modelo-anio-pieza-version.extension
```

Ejemplos:

```text
toyota-hilux-2020-soporte-plastico-v1.0.stl
nissan-qashqai-2016-tapa-interior-v1.2.step
pieza-original-frontal.jpg
informe-pruebas-v1.0.pdf
```

Evita utilizar nombres genéricos como:

- `archivo1.stl`
- `nuevo.stl`
- `final-final.stl`
- `imagen123.jpg`

## ⚠️ Seguridad y responsabilidad

Los diseños compartidos en este repositorio tienen fines
educativos, experimentales y de desarrollo tecnológico.

Las piezas deben someterse a pruebas de resistencia, temperatura,
ajuste, vibraciones y durabilidad antes de utilizarse en un
vehículo.

No se deberán utilizar piezas experimentales en sistemas críticos
de seguridad sin una validación profesional adecuada.

Esto incluye componentes relacionados con:

- Sistemas de frenos.
- Sistemas de dirección.
- Sistemas de suspensión.
- Sistemas de combustible.
- Cinturones de seguridad.
- Bolsas de aire.
- Componentes estructurales.
- Elementos de protección de los ocupantes.

La aprobación de una contribución en GitHub no representa una
certificación de seguridad automotriz.

Cada diseño deberá identificar claramente sus limitaciones y
las condiciones para las cuales fue evaluado.
