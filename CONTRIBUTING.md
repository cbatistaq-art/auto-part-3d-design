# 🤝 Guía de contribución

¡Bienvenido al proyecto Auto Part 3D Design!

Agradecemos tu interés en contribuir al diseño y fabricación de 
piezas plásticas automotrices mediante impresión 3D.

Esta guía establece los pasos y recomendaciones para colaborar 
de manera organizada en el proyecto.

## 🎯 ¿Cómo puedes contribuir?

Puedes participar de las siguientes maneras:

- Mejorando los diseños tridimensionales.
- Proponiendo nuevas piezas automotrices.
- Corrigiendo errores de diseño.
- Compartiendo medidas y especificaciones técnicas.
- Recomendando materiales de fabricación.
- Realizando pruebas de impresión 3D.
- Mejorando la documentación del proyecto.
- Compartiendo fotografías y evidencias de los resultados.

## 🚀 Pasos para contribuir

### 1. Realizar un Fork

Crea una copia del repositorio en tu cuenta de GitHub utilizando 
el botón **Fork**.

### 2. Clonar el repositorio

```bash
git clone https://github.com/TU-USUARIO/auto-part-3d-design.git
```

### 3. Acceder al proyecto

```bash
cd auto-part-3d-design
```

### 4. Crear una nueva rama

```bash
git checkout -b mejora-diseno-3d
```

### 5. Realizar los cambios

Desarrolla tus mejoras y coloca los archivos en las carpetas 
correspondientes.

### 6. Guardar los cambios

```bash
git add .
git commit -m "Mejora del diseño de la pieza automotriz"
```

### 7. Subir los cambios

```bash
git push origin mejora-diseno-3d
```

### 8. Crear un Pull Request

Desde GitHub, crea una solicitud de incorporación de cambios 
(Pull Request), explicando claramente las modificaciones realizadas.

## 📐 Requisitos para los diseños 3D

Todos los diseños deberán cumplir las siguientes recomendaciones:

- Utilizar milímetros como unidad de medida.
- Incluir dimensiones y tolerancias.
- Identificar la marca, modelo y año del vehículo.
- Incluir archivos STL y, preferiblemente, STEP.
- Documentar el material recomendado.
- Incluir fotografías o capturas del diseño.
- Evitar errores geométricos en los modelos.
- Documentar las pruebas de ajuste y funcionamiento.

## 📂 Organización de archivos

| Carpeta | Contenido |
|---|---|
| `modelos-3d/` | Diseños originales y editables |
| `archivos-stl/` | Archivos para impresión 3D |
| `archivos-step/` | Archivos CAD de intercambio |
| `imagenes/` | Fotografías y capturas |
| `documentacion/` | Especificaciones técnicas |
| `pruebas/` | Resultados y evidencias |

## 🐛 Reportar errores

Si encuentras algún problema, crea un **Issue** en GitHub 
incluyendo la siguiente información:

- Nombre de la pieza.
- Descripción del problema.
- Marca, modelo y año del vehículo.
- Fotografías o capturas del error.
- Posible solución, si está disponible.

## ✅ Lista de verificación

Antes de enviar una contribución, verifica lo siguiente:

- [ ] El diseño está correctamente documentado.
- [ ] Las dimensiones están expresadas en milímetros.
- [ ] Los archivos están en las carpetas correspondientes.
- [ ] El modelo no presenta errores geométricos.
- [ ] Se han documentado las pruebas realizadas.
- [ ] Se explica claramente la mejora propuesta.
- [ ] Se respetan los derechos de propiedad intelectual.

## ⚠️ Seguridad y responsabilidad

Los diseños compartidos en este repositorio tienen fines 
educativos, experimentales y de desarrollo tecnológico.

Las piezas deben someterse a pruebas de resistencia, temperatura, 
ajuste y durabilidad antes de utilizarse en un vehículo.

No se deberán utilizar piezas experimentales en sistemas críticos 
de seguridad, como frenos, dirección o suspensión, sin una 
validación profesional adecuada.

## 📜 Normas de convivencia

- Mantener una comunicación respetuosa.
- Valorar las ideas de otros colaboradores.
- Compartir conocimientos de manera constructiva.
- Respetar la autoría de los diseños.
- Promover el aprendizaje colaborativo.
- Evitar publicaciones ofensivas o discriminatorias.
