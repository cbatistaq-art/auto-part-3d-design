# 🧪 Pruebas y validación

Esta carpeta contiene los resultados de las pruebas realizadas
a las piezas fabricadas mediante impresión 3D.

## Objetivo

Evaluar la funcionalidad, resistencia, compatibilidad
y durabilidad de las piezas desarrolladas.

## Tipos de pruebas

- Prueba de dimensiones.
- Prueba de instalación.
- Prueba de ajuste.
- Prueba de resistencia mecánica.
- Prueba de temperatura.
- Prueba de vibraciones.
- Prueba de exposición solar.
- Prueba de durabilidad.

- 🟡 Requiere mejoras.
- 🔴 Prueba no aprobada.

## Seguridad

Las piezas experimentales no deberán utilizarse en sistemas
críticos de seguridad automotriz sin validación profesional.
