# 🚘 Auto Part 3D Design

## 📌 Descripción del proyecto

Este proyecto tiene como finalidad diseñar y fabricar una pieza 
plástica automotriz mediante herramientas de modelado e impresión 3D, 
ofreciendo una alternativa para la sustitución de componentes 
deteriorados, dañados o difíciles de conseguir en el mercado.

## 🎯 Objetivo general

Desarrollar una pieza plástica automotriz funcional mediante 
tecnologías de diseño tridimensional e impresión 3D.

## 📋 Objetivos específicos

- Identificar las características de la pieza original.
- Realizar la toma de medidas y dimensiones.
- Desarrollar un modelo tridimensional de la pieza.
- Seleccionar materiales adecuados para su fabricación.
- Fabricar un prototipo mediante impresión 3D.
- Evaluar su ajuste, resistencia y durabilidad.

## 🛠️ Herramientas y tecnologías

- Autodesk Fusion 360.
- FreeCAD.
- Blender.
- Impresora 3D.
- Calibrador digital.
- Materiales PETG, ABS o ASA.
- Archivos STL y STEP.
