# 📸 Imágenes del proyecto

Esta carpeta contiene las evidencias gráficas del proceso
de diseño, fabricación e instalación de las piezas
plásticas automotrices.

- Fotografías de la pieza original.
- Fotografías de la pieza dañada.
- Evidencias de la toma de medidas.
- Capturas del diseño tridimensional.
- Renderizados del modelo 3D.
- Fotografías del proceso de impresión.
- Fotografías del prototipo.
- Evidencias de instalación.
- Comparación entre la pieza original y la fabricada.
